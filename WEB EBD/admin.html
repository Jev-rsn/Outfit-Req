Buka Izin Hapus (RLS Supabase)

Jalankan script ini 1x di Supabase SQL Editor agar tombol hapus langsung menghapus data di database.

Mengapa data di database belum terhapus?

Supabase secara default mengaktifkan Row Level Security (RLS) yang hanya mengizinkan SELECT (baca) dan membatasi DELETE (hapus) / UPDATE dari browser. Script di bawah ini menonaktifkan batasan RLS dan memberikan izin penuh agar Konsol Admin dapat menghapus & mengubah data secara permanen.

Script SQL Supabase (docs/BUKA_IZIN_HAPUS_DATABASE.sql): 
-- 1. Nonaktifkan Row Level Security (RLS) pada seluruh tabel aplikasi
ALTER TABLE IF EXISTS public.outfit_catalog DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.users DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.premium_subscriptions DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.chat_quota DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.chat_rooms DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.chat_messages DISABLE ROW LEVEL SECURITY;
ALTER TABLE IF EXISTS public.saved_photos DISABLE ROW LEVEL SECURITY;

-- 2. Berikan izin akses penuh ke schema public
GRANT ALL ON ALL TABLES IN SCHEMA public TO postgres, anon, authenticated, service_role;
GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO postgres, anon, authenticated, service_role;
GRANT ALL ON ALL ROUTINES IN SCHEMA public TO postgres, anon, authenticated, service_role;
  1. Klik tombol "Salin Script SQL" di atas.
  2. Buka Supabase Dashboard → pilih project Anda.
  3. Di bilah kiri, klik SQL Editor → klik New query.
  4. Tempel (Paste) script ini dan klik tombol Run (atau tekan Ctrl + Enter).
